## 2. 版本规范

- **手动 bump**：版本号一律在 `package.json` 中显式修改（`0.3.4` → `0.3.5`），**不使用** vsce 的自动 bump。
- **显式指定包路径**：发布时必须显式给出 vsix 路径，避免工具自动触发 git tag / commit（遵守仓库的显式提交策略）。
- **改动同步**（发版前逐项确认）：
  - `CHANGELOG.md`（中文）与 `CHANGELOG.en.md`（英文）**成对**追加该版本条目，用户视角描述；
  - `README.md` 与 `README.en.md` 的兼容矩阵（若本次涉及 dsh 版本）；
  - `docs/02-Areas/dsh-baseline.json` 的 `extensionVersion`。
- **git tag**：`make tag` 只创建本地 tag，**不 push**；是否 push 需用户显式确认。
- **推送通道（2026-09-17 实测）**：HTTPS 侧凭据若缺 `workflow` scope，只要待推送的提交里含 `.github/workflows/*` 改动，GitHub 就会拒绝整条推送（`refusing to allow an OAuth App to create or update workflow … without workflow scope`——注意是**整条推送**被拒，不是只拒那个文件）。本机当时的 HTTPS 凭据（Git Credential Manager）与 `gh` 令牌都只有 `gist/read:org/repo`，故改用**本机已配置的 SSH 密钥**推送同一账号（不改 `origin` 配置）。要让 HTTPS 侧恢复可用：`gh auth refresh -s workflow`（交互授权）或换用带 `workflow` scope 的 PAT。
- **命名沿革**：扩展 id 在 v0.0.5 因 Marketplace 名称全局唯一而改为 `deepseek-harness-web-for-vscode`；2026-09-14 项目归属变更后改回 `deepseek-harness-for-vscode`，publisher 改为 `creatorliao`。**这是一次 id 变更**：新 id 在编辑器看来是一个不同的扩展，旧版本的设置与安装不会自动迁移。

## 3. 本地构建产物：`dist/`

```sh
npm run package
```

产出：`dist/creatorliao.deepseek-harness-for-vscode-<version>.vsix`

**规则（重要）**：

- `dist/` 下**永远只有一份** vsix——脚本会先清空 `dist/` 再打包，旧版本不会被留下；
- 文件名带 **publisher + name + version**，任何一个 vsix 都能一眼看出它对应哪个版本；
- 脚本会校验产物数量必须为 1，否则以失败退出（防止"以为打包成功其实没有"）；
- `dist/` 已在 `.gitignore` 中（构建产物不入库）；分发给用户走 GitHub Releases。

**导入方式**：VS Code / Cursor → 扩展视图 → 右上角 `...` → **Install from VSIX...** → 选择 `dist/` 下的文件。

## 5. Makefile 快速参考

> Makefile 是 POSIX/bash 专用（`SHELL := /bin/bash`、`test -n`、`rm -rf`）。Windows 下需在 bash 环境（Git Bash / WSL / MSYS）中执行，或直接跑对应的 npm 命令。**该限制尚未在 Makefile 内标注，属待改进项。**

| 命令 | 作用 |
|---|---|
| `make install` | 安装依赖（缓存到 `.npm-cache`） |
| `make compile` | `tsc` 编译 |
| `make watch` | 增量编译 |
| `make test` | 编译 + 单测 |
| `make package` | 编译 + 打包到 `dist/`（唯一一份 vsix） |
| `make publish` / `make publish-vscode` | ⚠️ **当前不可用**（Marketplace 半边已失效） |
| `make publish-ovsx` | 发到 Open VSX（需 `OVSX_TOKEN`） |
| `make namespace` | 一次性创建 Open VSX namespace（需 `OVSX_TOKEN`） |
| `make tag` | 创建本地 tag `v<version>`（**不 push**） |
| `make clean` | 清理 `*.vsix` 与 `out/` |

**令牌只从环境变量读**（`VSCE_PAT`、`OVSX_TOKEN`），仓库内不存任何令牌；用到令牌的 recipe 以 `@` 开头，避免回显。
