## 本夹是什么

用户提出的体验诉求：像 Cursor 一样，把资源管理器（目录树）里的文件直接拖进 DSH 输入框，AI 立刻知道"我要改的就是这个文件"，而不是先手动打 `@` 再搜索选中。
