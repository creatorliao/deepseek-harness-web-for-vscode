# 事件 — 热升级内核导致运行中的会话工具链失效（升级 dsh 后一切命令都起不来）

**日期**: 2026-09-15
**扩展版本**: v0.3.4（与扩展代码无关，属**操作事故**）
**dsh 版本**: `0.1.5-rc.1` → `0.1.5-rc.2`（npm 全局包）
**影响面**: **执行升级动作的那个正在运行的 DSH 会话**——所有需要起子进程的能力立刻失效（宿主 shell、文件搜索、任何通过 Node 加载器起的子进程）；其他会话/新起的进程不受影响
**范围**: 无代码改动。产出：本文 + [内核升级最佳实践](../../02-Areas/20260915-01-内核升级最佳实践.md)
**根因归属**: 平台差异（Windows 文件锁）+ 操作顺序（在活跃会话上热升级）
**关联**: [内核升级最佳实践](../../02-Areas/20260915-01-内核升级最佳实践.md) ｜ [上游兼容规范](../../02-Areas/20260914-06-上游兼容规范_跟随最新官方DSH.md)

## 现象

在一个**正在运行的 DSH 会话里**执行 `npm install -g @deepseek-ai/dsh@0.1.5-rc.2` 之后：

1. 安装本身**成功**：`added 64 packages, and changed 520 packages in 54s`，磁盘上 `@deepseek-ai/dsh/package.json` 的 `version` 已变成 `0.1.5-rc.2`；
2. 但**该会话的每个"起子进程"的工具调用都失败**，且报错有三种、彼此不同：

| 原文报错 | 触发它的操作 |
|---|---|
| `Error [ERR_MODULE_NOT_FOUND]: Cannot find package 'tsx' imported from D:\code\deepseek-harness-web-for-vscode\` | 以 Node 启动的子进程（带 `--import tsx` 风格加载器） |
| `subprocess-local: Windows Job runner exited with exit code 1 before proving its managed range empty` | 宿主起 shell / 子进程管理 |
| `ripgrep provider failure` | 文件搜索类工具（grep / glob） |

3. 安装时另有 cleanup 警告，**原生 DLL 被在跑的进程锁住**：

```
npm warn cleanup EPERM unlink
  …\@deepseek-ai\.dsh-YBMFo6rE\node_modules\@img\sharp-win32-x64\lib\libvips-42.dll
```

## 根因

### A. 确定：升级把**正在运行的那棵树的文件**换掉了

npm 全局安装会重写 `%AppData%\npm\node_modules\@deepseek-ai\dsh`（本次 520 个包被 changed）。运行中的进程内存里是 rc.1 的代码，落盘的是 rc.2 的树 —— **新旧混用**。Windows 又因 DLL 占用拒绝清理临时目录，进一步说明"进程还抓着旧文件"。

### B. 已观察 + 待复核：子进程加载器解析不到它依赖的包

报错指向包 `tsx`。已核实的**事实**：

- 升级后 `%AppData%\npm\node_modules\tsx` **不存在**；
- 本仓 `node_modules/tsx` 不存在，`package.json` 也没有该依赖；
- 安装后的 `@deepseek-ai/dsh/lib/` 里**没有任何 `tsx` 引用**。

**未确证的部分**（当时用于取证的 grep / npm 日志通道随后一起失效，故不下结论）：`tsx` 究竟来自旧树的传递依赖、还是全局包、还是启动时的 `NODE_OPTIONS`，需要在重启后的干净环境里复核。**不要把 B 当结论传播**。

### C. 与扩展代码无关

本次没有改任何 `src/**`；事故是**操作顺序**问题：升级动作与"继续使用那个会话"互斥。

## 修复

无代码修复。恢复动作（用户侧）：

```powershell
# 1) 重启内核：关掉 DSH / IDE 面板 / 终端里的 dsh web，再重新打开
# 2) 若重启后仍报 Cannot find package 'tsx'
npm i -g tsx
# 3) 若新内核本身起不来，回退到已适配版本
npm i -g @deepseek-ai/dsh@0.1.5-rc.1
```

## 验证

| # | 项 | 结果 |
|---|---|---|
| 1 | 升级后磁盘版本 = 目标版本 | ✅ 已读 `package.json`：`0.1.5-rc.2` |
| 2 | 升级残留 staging 目录是否还在 | ✅ 已复查：`@deepseek-ai\.dsh-YBMFo6rE` 已不存在 |
| 3 | **四破坏面复核（A–D）** | ⏳ **未做**——本会话工具链已失效，须在重启后的干净环境执行（见 SOP §6） |
| 4 | `npm run compile` / `npm test` / `node scripts/smoke.js` | ⏳ 未做（同上） |
| 5 | 扩展面板在 rc.2 下真机可用 | ⏳ 未做 |
