## 本夹是什么

来源是一条现场 VOC（[VOC20260929-01](../../03-Resources/VOC20260929-01-活动栏孤儿图标与常驻视图.md)）。
用户报了三件事：活动栏上多出两个名字一样、没有图标的 DeepSeek Harness；拖拽投放条常驻在资源管理器里关不掉；两个容器同名同图标分不清。

调查结论：第一条的真因是 **2026-09-14 那次容器 id 改名**留下的孤儿 pin，属于旧版兼容遗留；
第二条是本仓自己 `R20260917-01` 的 `E3` 条已经写明过、现在由现场确认不接受的代价；第三条是 `package.json` 两处 `title`/`icon` 完全相同。
