# R20260918-02 跨端会话可见性

**日期**: 2026-09-18 ｜ **状态**: 调查已收口，方案待用户确认
**定位**: 回答"在 VSCode 里写的对话，到 DSH Desktop 上只显示一部分——是什么情况、为什么、两者到底怎么共享数据"，并给出改善方案。

---

## 1. 这个夹是什么

用户提出：本机同时装了 DSH Desktop 与 DeepSeek Harness for VS Code，发现**在 VSCode 里写的对话，到 desktop 上只展示一部分**，怀疑"原有的东西没展示齐全"，并问两端对话是否互相引用、是否从同一个地方读取。

本夹记录这次调查的**需求、证据、根因分析与改善方案**。结论一句话：

> 两端**确实**读同一个 `$DSH_HOME`、同一批会话文件、同一个 dsh 版本；"只显示一部分"**不是两端存储分叉**，而是 DSH 上游的**工作区成员资格闸门**把会话从列表里静默剔除。本机实测 **76 个根会话数据完好但界面不可见**。
