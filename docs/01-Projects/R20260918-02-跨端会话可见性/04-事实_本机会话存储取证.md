## F3 会话物理布局与格式代际

**布局**：`$DSH_HOME\sessions\<项目slug>\<sessionId>\session.v<N>.jsonl.zstd`

**slug 规则**（由本机 41 个目录反推，并用 `D:\obsidian-vaults\项目空间` → `--D-obsidian-vaults-~9879~76EE~7A7A~95F4--` 验证）：
去掉盘符冒号 `:`，`\` / `/` → `-`，非 ASCII 字符按 UTF-16 码元转 `~XXXX`（大写十六进制），两端包 `--`。

**格式代际（全库统计）**：

| 文件 | 数量 | 说明 |
|---|---|---|
| `session.v3.jsonl.zstd` | 323 | 现行代际（v3） |
| `session.jsonl.zstd` | 70 | 原始代际（v0，后缀无版本号） |
| 两种并存于同一会话目录 | 9 | 已迁移，旧档保留 |

**读取器行为**（`@deepseek-ai/dsh-session-persistence-jsonl@0.1.5-rc.2` `lib/index.js`）：

- `:752-762` `generationLogFilename(version, compression)`：v0 保留无版本号旧名，之后每代带小写 `vN`。
- `:3160-3191` `resolveGenerationInDirectory()`：取**数值最高**的规范代际。
- `:2486-2511` `requireStoredLog()`：`sourceVersion < SESSION_FORMAT_VERSION` 时走**懒迁移**（`prepareJsonlMigration`），即**只有被打开过的旧会话才迁移**。
- `:963-966` `refuseForeignFormatVersion()`：**未来版本**的 header 会被显式拒绝（`SessionFormatUnsupportedError`）。

**并存的 9 个会话，旧档显著大于 v3 档**（迁移含压缩/去冗余），例：

```

--D-code-deepseek-harness-web-for-vscode-- / session-2ab6f301-…  old=5 191 893 B  v3=1 722 872 B
```

**全量头部可解析性**：脚本解压 386 个会话的首帧并解析首行 JSON → **成功 386，失败 0**。其中 `isSeeded=true` 共 10 个，全部 `origin=subagent`。
