## 本夹是什么

项目的立身之本：**怎么把 DSH 的 Web UI 塞进 VS Code 编辑器标签页**。包含 MVP 立项、传输桥架构的全部设计论证、Phase 0 实测事实，以及本主题相关的若干缺陷记录。

核心结论：webview **不能**直连 DSH 前端（跨源 iframe 剪贴板不可用的致命否决项）→ 改为"文档直载 + postMessage 传输桥 + 扩展宿主 Node 代发"。
