# 侧边栏版式重设计 — 方案

**日期**: 2026-09-15 ｜ **状态**: ⏳ 草案（待 [01-需求](01-需求_侧边栏打开入口与版式重排.md) 批准后确认）｜ **来源**: 需求（2026-09-15）+ `src/` 代码事实

> 每一句"改为 xxx"都有 §2 核实过的代码事实支撑；行号对应 `0.3.4`（`package.json:5`）工作区。

---

## 1. Goal

侧边栏（活动栏 DeepSeek Harness 视图）重排为四段，**按使用频率自上而下**：

```
┌ header ─────────────────────────────────┐
│ [logo] DeepSeek Harness                 │
│        extension v0.3.4                 │
├ ① 动作区（高频）────────────────────────┤
│ [◧] 在右侧面板打开        ← primary     │
│ [▤] 在编辑器打开          ← secondary   │
│ [🌐] 在浏览器中打开        ← secondary   │
├ ② 会话区（高频，占满剩余高度）──────────┤
│ 会话                              [＋]  │
│ ● 新会话              1m   ✎   ✕        │
│ ● …                                     │
│ ▸ 归档 (1)                              │
├ ③ 底部区（低频，沉底）──────────────────┤
│ ↑ 预览版更新（next）：0.1.5-rc.2     ›  │
│ ● dsh 0.1.5-rc.1 运行中          停止   │
│   http://127.0.0.1:16257                │
│ 工作区: deepseek-harness-web-for-vscode │
└─────────────────────────────────────────┘
```

设计目标三条：**高频上移**、**打开入口成组分主次**、**文案左对齐 + 图标锚点**。行为语义零变更。

| 缺口 | 现状 | 目标 |

## 4. 设计规格

### 4.1 动作区（R1/R3/R4）

```html
<div class="open-group">
  <button class="btn primary" id="openChatPanel">
    <svg …/>  <!-- layout-sidebar-right --><span class="lbl">在右侧面板打开</span>
  </button>
  <button class="btn secondary" id="openChatEditor">
    <svg …/><span class="lbl">在编辑器打开</span>
  </button>
  <button class="btn secondary" id="openChatBrowser">
    <svg …/><span class="lbl">在浏览器中打开</span>
  </button>
</div>
```

```css
.open-group { display: flex; flex-direction: column; gap: 6px; }
.btn {
  display: flex; align-items: center; gap: 8px;
  width: 100%; padding: 7px 10px;
  font: inherit; font-size: 13px; text-align: left;
  border: none; border-radius: 4px; cursor: pointer;
}
.btn svg { flex: none; opacity: .9; }
.btn .lbl { flex: 1 1 auto; min-width: 0; overflow: hidden; text-overflow: ellipsis; white-space: nowrap; }
```

**为什么是"竖排三步"而不是并排**（这是本方案最关键的取舍）：

| 形态 | 300px 栏宽 | 最窄 170px 栏宽 | 结论 |
|---|---|---|---|
| 竖排三步（推荐） | 舒适 | 最长标签「在浏览器中打开」7 字 ≈ 91px + 图标 16 + 间隙 8 + 内边距 20 ≈ **135px < 170px**，仍可读 | ✅ |
| 三段式 segmented 一行 | 每段 ≈ 88px，「在右侧面板打开」7 字必然截断 | 更不可行 | ❌ |
| 主按钮 + 两列并排 | 每列 ≈ 128px，勉强 | 每列 ≈ 65px，必须加断点 | ❌ |

中文按 `--vscode-font-size` 默认 13px、单字宽 ≈ 字号估算；这是**设计期估算**，实施后用真机窄栏复测（A4）。

主/次层级：主入口用 `--vscode-button-background` 填充，次入口用 `--vscode-button-secondaryBackground`；hover / focus-visible 沿用现有令牌（`:118-122`）。

### 4.2 会话区（R5）

```html
<div class="sessions-head">
  <span class="sessions-title">会话</span>
  <button class="icon-btn" id="newSession" aria-label="＋新建会话">＋</button>
</div>
```

会话行本身**一行不改**（F15：历史修复点，改它等于把修好的对齐再打破）。

### 4.3 底部区（R2）

```html
<div class="bottom">
  <button class="update-row" id="upgradeNext">…<span class="chev">›</span></button>
  <div class="status-row">
    <span class="dot ready"></span>
    <span class="status-text">dsh 0.1.5-rc.1 运行中</span>
    <button class="link-btn" id="stop">停止</button>
  </div>
  <div class="status-url">http://127.0.0.1:16257</div>
  <div class="footer">工作区: deepseek-harness-web-for-vscode</div>
</div>
```

```css
.bottom { margin-top: auto; display: flex; flex-direction: column; gap: 6px;
          padding-top: 8px; border-top: 1px solid var(--vscode-panel-border, var(--vscode-widget-border)); }
.update-row { display: flex; align-items: center; gap: 6px; width: 100%;
              background: transparent; border: none; text-align: left; cursor: pointer;
              color: var(--vscode-notificationsInfoIcon-foreground, var(--vscode-charts-blue, #3794ff));
              font: inherit; font-size: 12px; padding: 5px 6px; border-radius: 4px; }
.update-row:hover { background: var(--vscode-list-hoverBackground, rgba(128,128,128,.1)); }
.update-row .chev { margin-left: auto; opacity: .7; }
.status-row { display: flex; align-items: center; gap: 8px; font-size: 12.5px; }
.status-row .status-text { flex: 1 1 auto; min-width: 0; overflow: hidden; text-overflow: ellipsis; white-space: nowrap; }
.link-btn { background: transparent; border: none; color: var(--vscode-descriptionForeground);
            font: inherit; font-size: 12px; padding: 3px 6px; border-radius: 3px; cursor: pointer; }
.link-btn:hover { background: var(--vscode-list-hoverBackground, rgba(128,128,128,.15)); color: var(--vscode-foreground); }
.status-url { font-size: 11px; color: var(--vscode-descriptionForeground); word-break: break-all; padding-left: 17px; }
```

三条设计理由：
1. **状态与停止同行**：被动信息 + 唯一能改变它的动作，就近成组，符合语义（用户诉求第 1 点）。
2. **更新提示降级为信息行**：不再是与主操作同等重量的描边大按钮。
3. **URL 降级为 11px 副行**：新增浏览器入口后手工复制 URL 的必要性下降，排障时仍可见。

### 4.4 状态矩阵（不新增状态逻辑）

沿用现有 `showStart/showReady` 判断（`src/launcherView.ts:56-57`），只改呈现：

| 服务状态 | ① 动作区 | ③ 底部状态行 |
|---|---|---|
| stopped | `启动 DeepSeek Harness`（primary） | ● 未启动 |
| starting | `启动中…`（primary，disabled） | ● 启动中… |
| ready | 三个入口 | ● dsh `<版本>` 运行中 ｜ 停止 ｜ URL |
| stopping | `停止中…`（primary，disabled） | ● 停止中… |
| error | `启动 DeepSeek Harness`（primary）+ 红色错误行 | ● 错误：`<message>` |

任何状态下面板都有**恰好一个**主操作，不再出现"整块空白"（对应 A5）。

### 4.5 可访问性与主题

- 图标 `aria-hidden="true"`；三个入口都有可见文字标签，不依赖 `aria-label`。
- `:focus-visible` 轮廓保留（`src/launcherView.ts:118`）。
- 行高 ≥ 28px；会话行内的 20×20 图标按钮维持不变。
- 颜色一律走 `--vscode-*` 令牌，无新增硬编码（A6）；`：root{color-scheme: light dark}` 保留。

### 4.6 i18n

| 键 | 文案 | 说明 |
|---|---|---|
| `button.openChatBrowser` | 在浏览器中打开 | 新增；与命令标题（`package.nls.json:4`）用词一致 |
| `button.stopShort` | 停止 | 新增；底部状态行宽度有限，复用 `button.stop` 会撑破行 |

（i18n 单测只校验"每个键非空、无多余语言列"，新增键自动被覆盖 —— `test/i18n.test.js:11-29`。）

## 6. 备选方案与取舍

| 方案 | 取舍 | 结论 |
|---|---|---|
| **A 竖排三步**（主 + 两次） | 170px 最窄栏仍可读，零断点；代价是占 ~100px 高度 | ✅ **推荐** |
| B 三段式 segmented 一行 | 省 ~70px；中文标签在 300px 栏下被截断，且把默认形态与备选形态画成同级 | ❌ 否决 |
| C 主按钮 + 两列并排 | 视觉紧凑；最窄 170px 时每列 ≈ 65px，必须加断点，复杂度换不来收益 | ❌ 否决 |
| D 主入口挂"默认"徽标（跟随 `openTarget`） | 让设置可见；但需把 `openTarget` 当前值推入 webview，新增一条状态同步路径 | ⏭️ 本轮不做（AGENTS §2 最小实现） |

3. 窄栏拖到最窄 170px：三个标签不溢出/不换行（A4）——设计期按字号估算，**必须真机复测**。
