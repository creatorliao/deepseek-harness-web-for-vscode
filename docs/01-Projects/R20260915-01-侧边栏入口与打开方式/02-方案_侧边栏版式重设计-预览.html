这一版改了什么（对照左侧）

  1. 频率重排：状态卡与更新按钮从首屏移到最底部；首屏从上到下是「打开入口 → 会话列表」。
  2. 打开入口成组、分主次：一个 primary（右侧面板，默认形态）+ 两个 secondary（编辑器 / 浏览器），三者左对齐、带前置图标，起始边界成一条竖线，扫读成本最低。
  3. 新增第三个入口「在浏览器中打开」——复用已有命令能力（manager.browserUrl，带启动 token）。
  4. 停止与状态同行：被动状态 + 唯一能改变它的动作就近成组，不再夹在打开入口中间。
  5. 更新提示降级为信息行：不再是和主操作同等重量的描边大按钮；仍保留 latest / next 两个渠道可分别点击。
  6. 会话区上移：「＋新建会话」并入「会话」标题行，省掉一整行（约 36px）。会话行本身一行未动。
  7. 窄栏验证：把滑杆拖到最左（170px）——「在浏览器中打开」仍单行可读，不溢出、不换行（竖排三步的取舍依据）。
  8. 状态矩阵：点顶部「未启动 / 启动中 / 错误」，动作区始终只有一个主操作，不会出现点不动的打开入口。
