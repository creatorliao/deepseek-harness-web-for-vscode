# R20260915-01 · 侧边栏入口与打开方式

**起始**: 2026-09-15 ｜ **状态**: ⏳ 需求与方案已写，待用户批准后实施 ｜ **属性**: 特性（走特性管线）

## 本夹是什么

用户提出的一条界面需求：**侧边栏（活动栏的 DeepSeek Harness 视图）里增加第三个入口「在浏览器中打开」，并把这一块的版式重新设计**——
把运行状态、更新提示、停止按钮下沉到底部，让"在哪里打开"和会话列表这些高频内容占据首屏。

本夹按 [特性管线规范](../../02-Areas/20260914-04-特性管线规范.md) 落盘：`01-需求` →（批准）→ `02-方案` →（批准）→ `04-实施计划` → 实现 → `05-验证`。
