# R20260918-04 · 上游 0.1.6-alpha 差距与升级

**起始**: 2026-09-18 ｜ **状态**: 进行中（文档已交付，待用户批准；**未实施升级、未改代码**）｜ **属性**: 需求 + 方案 + 证据

## 本夹是什么

回答一个问题：**官方最新发布的 `@deepseek-ai/dsh` 跟我们当前在用的版本差在哪，升上去值不值、怎么升。**

**背景（一句话）**：官方 2026-09-17 发了 `0.1.6-alpha.2`，而我们在用的 `0.1.5-rc.2` 停在 2026-09-10。两者之间隔了**两个版本、7 天**的改动量（依赖树 520 → 488 包，新增 58 / 移除 90），而本项目**从未记录过"上游到底改了什么"**——用户问"升上去有什么好处"时答不出来。

**读者口径**：终端用户（升级说明 / 发布公告）。因此主线是体感与价值，内部实现只作佐证。

## 核心结论（三句）

1. **差距是真实的**：`0.1.6-alpha.2` 比 `0.1.5-rc.2` 多两个版本、7 天；新增 58 包 / 移除 90 包 / 229 包换版本。
2. **对本扩展零破坏**（实测）：四破坏面 A–D **形态全同**，baseline 登记的 9 个脆弱点**全部仍在**，`node scripts/smoke.js` 两个版本都 exit=0。
3. **但代价是真的**：`alpha` 是官方实验通道（`check:dsh` **不跟踪**）；磁盘 **222.9 → 560.6 MiB**（+325.1 MiB 来自 Office 预览的 LibreOffice）。**顺带好消息**：启动快约 3 倍（10.3–11.3 s → 3.5–3.9 s）。
