## 2. 全貌速览（一张图看懂入口）

```
┌ 命令面板（6 个命令）
├ 快捷键 ctrl+alt+a / cmd+alt+a（1 个）
├ 资源管理器右键菜单（1 个）
├ 活动栏图标 → 启动器视图（状态 + 7 类按钮 + 会话列表）
├ 次级侧边栏 → DSH UI 本体
├ 状态栏按钮（4 种状态，点它=启动/重试/打开面板）
├ DSH 界面内覆盖层（未启动时的"启动"按钮）
├ DSH 界面内：拖拽 → @ 引用、剪贴板、粘贴图片
└ 自动触发：激活/点图标/重载同工作区/切主题/dsh 就绪
```

**数量口径**（`package.json` 的贡献点）：命令 **6**、快捷键 **1**、菜单 **1**、视图容器 **2**、视图 **2**。

## 3. 仍未闭环

| 项 | 说明 |
|---|---|
| 未做真机逐项点验 | 本夹内容来自源码与清单（`package.json`、`src/`、`media/`），**未在面板里把每个按钮都手点一遍** |
| 命令标题与行为的细微不一致 | `openChatView` 的清单标题是"在右侧面板打开"（`package.nls.json:5`），而它实际是"聚焦次级侧边栏容器"；行为正确，措辞可再打磨 |
| **状态栏点击不遵循 `openTarget`** | `ready` 时状态栏恒绑定 `openPanel`（编辑器标签页，`src/statusBar.ts:8,36`），默认 `sidebar` 的用户会拿到标签页；与 AGENTS.md §7 的"单一路由点"口径冲突，**未修**，详见 [01 §6](01-分析_命令与入口全清单.md) |
| 会话列表轮询是固定 5s | 无设置项，也无手动刷新按钮（`refresh-sessions` 消息存在但界面没有对应按钮，`src/launcherView.ts:504-506`） |
