# VS Code 扩展外部依据

**日期**: 2026-09-14 ｜ **状态**: 活文档 ｜ **定位**: 本项目绕行方案所依赖的**外部事实与上游 issue**——遇到"为什么不能直接这么做"时看这里

---

## 1. Webview 剪贴板（决定了整个架构）

| 项 | 内容 |
|---|---|
| 事实 | webview 内**跨源 iframe** 的 `navigator.clipboard` 一律 `Write permission denied`；`allow="clipboard-read; clipboard-write"` 无效；原生 `Cmd+C/V` 同样不可用 |
| 上游 issue | [microsoft/vscode#182642](https://github.com/microsoft/vscode/issues/182642)（open，2023 起未修复）、[microsoft/vscode#129178](https://github.com/microsoft/vscode/issues/129178) |
| 影响 | 若采用"iframe 内嵌 DSH Web UI"方案，聊天窗无法复制代码块、无法粘贴长文本——**核心交互缺失** |
| 本项目的对策 | 放弃 iframe，改为**文档直载 + 传输桥**：DSH 前端直接加载进 webview 文档，注入 `navigator.clipboard` shim → `postMessage` → `vscode.env.clipboard` |
| 代码位置 | `media/bridge-client.js`（shim）、`src/bridgeHost.ts`、`src/bridgeCore.ts` |
| 记录 | [Phase 0 实测笔记 V8](../01-Projects/R20260817-01-桥架构与IDE内嵌/08-事实_Phase0实测笔记.md) |

**这是本项目的架构分水岭**：不是"选了个方案"，而是 iframe 方案被一个未修复的上游 bug 判了死刑。

## 2. Webview 主题与设置

| 项 | 内容 |
|---|---|
| 事实 | webview 内的嵌入式页面**读不到**宿主 VS Code 的设置/主题状态；`prefers-color-scheme` 在 webview 里不可靠 |
| 本项目的对策 | ① 主题：宿主向 DSH 的 `/api/settings.update` 写 `ui-theme` + 注入 `matchMedia` shim；② 其余设置（locale 等）**尚无上游 API** → 只能提上游 issue（待办 G-05） |
| 代码位置 | `src/themeSync.ts` |
| 颜色规则 | 一律用 `var(--vscode-*)` 主题变量，禁止硬编码颜色（见 [扩展与 Webview 规范](../02-Areas/20260914-02-扩展与Webview规范.md)） |

## 3. Webview CSP 与资源加载

| 项 | 内容 |
|---|---|
| 事实 | webview 必须带 CSP；外部资源裸跨源引用会因 CORS 失败 |
| 本项目的对策 | `default-src 'none'` + 最小授权；`connect-src 'none'`（所有网络调用被传输桥拦截，不需要 webview 直连）；资产经 `asWebviewUri` 以**同源**形式加载 |
| 代码位置 | `src/documentAssembly.ts`（CSP 常量与文档组装） |
| 教训 | dist 的 shell bundle 用相对 import（`./vendor-*.js`），因此资产**必须**同源加载——这直接决定了 `documentAssembly` 的改写策略 |

## 4. 扩展本地化（i18n）

| 项 | 内容 |
|---|---|
| 机制 | 扩展名/命令/设置描述用 `package.nls.json`（VS Code 要求的默认文案文件）+ 可选的 `package.nls.<locale>.json` 变体；代码内用户可见字符串可用 `vscode.l10n.t()`（VS Code ≥ 1.73） |
| 本项目实现 | **刻意只做简体中文**（2026-09-14 决定：维护 8 份额外翻译的成本远大于收益）。中央字符串表 `src/i18nStrings.ts`（每行只有 `zh`）+ `src/i18n.ts` 的 `t()`；`package.nls.json` 内容即中文，**已删除 `package.nls.zh-cn.json`**，因此任何 locale 都不会回落到英文 |
| 规则 | `test/i18n.test.js` 校验每个键的中文非空、且**不含多余语言列**（防止合并时把删掉的语言带回来） |
| 引擎要求 | `engines.vscode: ^1.90.0` |
